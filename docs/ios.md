# iOS

仿系统键盘的五笔。版本 **1.0.1**。键盘扩展里跑同一套 `wubi86_jidian`。键帽、预览气泡、点击音和触感按系统键盘来。候选在键盘上方横排，点按上屏。造词和自动同步与 Mac 共用账号，细节在 [痛点解决](/pain)。

## iOS 上的做法

- **三页键盘。** 字母、数字、符号。深浅色跟着系统走。
- **候选在键盘上方。** 点候选上屏，也可以展开看更多。
- **键盘里就能造词。** 写入用户词后马上能打出来。主 App 里可以按分组管理、导入和导出。
- **完全访问。** 造词、共享词库和同步需要开启「允许完全访问」。关掉时仍可用内置方案做基础输入。
- **自动同步的节奏。** 打开后约 2 秒查一次，改词后约 3 秒再同步，留在前台时大约每 10 分钟查一次。退到后台后，下次打开再补。
- **局域网里改配置。** 手机和电脑在同一 Wi-Fi 时，可以用浏览器查看、上传、删除 Rime 配置，再回 App 里部署。也可以一键复位到内置方案。
- **标点与 Mac 相同。** 每一键的输出和上屏方式可以改。

## 启用

1. 安装「玫枫五笔」。
2. 设置 → 通用 → 键盘 → 键盘，添加「玫枫五笔」。
3. 造词和共享词库需要打开「允许完全访问」。
4. 在任意输入框点地球键，切换到玫枫五笔。

安装包确定后放在 [下载](/download)。
