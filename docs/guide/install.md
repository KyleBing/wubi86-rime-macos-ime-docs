# 开始输入

各系统怎么装进输入法列表，写在对应的系统页，不写在这里。

- [macOS](/macos)：从 [下载](/download) 拿到 DMG，拖进「应用程序」，再到系统设置里启用。
- [iOS](/ios)：在系统键盘列表里添加，造词和同步要开完全访问。

切换到玫枫五笔之后，打法是同一套 `wubi86_jidian`。

## 选词

- 空格上屏第一个候选。
- 数字 `1`–`9` 选对应序号。
- 打不出的词用 [自造词](/guide/custom-words) 加进去。
- 要填当前日期、时间或星期，输入 `date`、`time` 或 `week`。见 [日期与时间](/guide/date-time)。

四码唯一时会自动上屏。`date` 这种有多项候选的编码不会自动上。不会拆的字用 `z` 加拼音反查，见 [快捷键](/guide/shortcuts)。

macOS 上的 Shift、造词快捷键和设置入口见 [macOS](/macos)。
