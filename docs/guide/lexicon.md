# 词库与同步

用户词、扩展词库和主码表是分开的。自造词进用户词，不改主码表文件。同步规则各端相同。下面「在 macOS 的设置里」才是 Mac 上的界面。

## 用户词

词按分组存放。添加时填写词条和编码。有单字字典时，编码会按 [自造词](/guide/custom-words#编码怎么来) 同一套规则生成。分组可以新建、重命名、删除。删分组不会把词条散到别处。快捷造词写入当前选中的分组。

iOS 在主 App 里管理这些分组。Mac 的界面见文末。

## 和手机、码表助手同步

登录 portal 账号，和码表助手、iOS、Mac 是同一个账号。默认地址是 `https://kylebing.cn/portal/`。

登录之后可以：

| 操作 | 结果 |
| --- | --- |
| 对比差异 | 只拉取云端内容做比较，不改本地 |
| 增量合并 | 保留本地词条，并入云端多出来的 |
| 本地 → 云端 | 用本地覆盖云端 |
| 本地 ← 云端 | 用云端覆盖本地 |

箭头指向被覆盖的一侧。覆盖前建议先对比一次。

## 扩展词库

扩展词库和用户词、主码表分开。从线上获取时，会用线上内容覆盖本地扩展文件，不能在这个操作里逐条编辑。获取前请确认本地扩展词库没有需要留下的改动。Mac 上这个按钮在「用户词」页，叫「获取扩展词库」。

## 在 macOS 的设置里

「设置 → 用户词」左边是分组，右边是词条。可以添加、改编码、拖动排序、重命名或删除分组。删分组不会把词条散到别处。快捷造词写入当前选中的分组。

「设置 → 账户」登录。登录后回到「用户词」页做对比、合并和覆盖。

「词库目录」管理 Rime 用户数据放在哪，以及重新部署、复位。

「单字字典」从当前选中的主码表抽出单字编码，供添加词条和快捷造词自动生成词组编码。换了主码表后，在这里重新生成一次字典。
