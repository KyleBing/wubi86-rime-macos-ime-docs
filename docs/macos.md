# macOS

系统输入法，候选不抢当前窗口。版本 **1.0.2**。用 InputMethodKit 跑同一套 `wubi86_jidian`。编码以下划线留在插入点，候选是一块不激活的浮窗。各端相同的打法见 [开始输入](/guide/install)，造词、同步和日期见 [痛点解决](/pain)。

## macOS 上的做法

- **编码留在插入点。** 还没上屏的字母以下划线画在光标处。切走输入法时，未上屏的编码和候选会清掉。
- **候选不抢焦点。** 候选条是不激活的面板。横排或竖排、明暗两套颜色跟着系统外观走。详见 [外观](/guide/appearance)。
- **可以盲打。** 候选可以收成圆点，或完全藏起来。数字键、空格和翻页键仍然能选词。
- **单按 Shift 切换中英。** 按下再松开、中间没有别的键，就切换，光标旁会短暂出现模式提示。按住 Shift 打大写不算切换。
- **快捷键按五笔习惯。** 见 [快捷键](/guide/shortcuts)。
- **确认后再删候选。** 用造词那组修饰键加数字打开确认框。见 [自造词](/guide/custom-words#删除候选)。
- **设置键留给各个 App。** 输入法菜单不再占用 `⌘,`。玫枫五笔的设置从菜单栏输入法图标进入。

## 安装

1. 打开 DMG，把「玫枫五笔」拖到「应用程序」。
2. 运行「玫枫五笔」，点「安装 / 更新输入法」。
3. 系统设置 → 键盘 → 输入法。已经启用的话，用菜单栏输入法图标切换。
4. 列表里还没有：点「+」→ 简体中文 → 玫枫五笔。
5. 安装后列表仍不出现时，注销一次再看。

设置从菜单栏输入法图标里的「玫枫五笔设置…」进入，也可以在主窗口点「打开输入法设置」。

主窗口有「修复 / 清理重复项」，用来清掉构建目录里误注册的副本。平时不用点。

装好之后单独按一下 Shift，确认是中文模式，然后按 [开始输入](/guide/install) 里的方式打。macOS 按键见 [快捷键](/guide/shortcuts#macos)，候选外观见 [外观](/guide/appearance)。
