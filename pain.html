macOS iOS Windows Android 痛点解决

各端共用 · 独立于系统页面

Rime 五笔用久了会烦的地方，在这里处理。

macOS、iOS，以及以后的 Windows、Android，输入引擎都是 librime，方案都是 rime-wubi86-jidian。这一页只写大家都会有的能力。某个系统怎么摆候选、怎么装，去对应的系统页。

同一套编码，各端上屏方式相同

都会有的功能

还是原来的五笔方案

方案 id 是 wubi86_jidian，码表是 86 极点。不另做一套编码，也不靠 Lua 改候选。四码唯一时自动上屏，date 这种多项候选不会自动上。

快捷键自造词

不用打开词库文件再部署。Mac 上默认是 Control + Option + N；iOS 在键盘里直接造。选中的文字或刚上屏的词会填进去，编码按五笔规则生成，写完马上能打。

词库自动同步

和码表助手、其他端共用 portal 账号。先查云端修订号，词库没变化就不再整份下载。本地删掉、云端没改过的词不会被加回来。推送冲突会重新合并再推一次。

用户词和主码表分开

自造词进用户词，按分组管理。主码表文件不动。同编码的词会标出来自用户词、扩展词库还是主词库。

标点由输入法处理

可以改每一键打出什么，并选择直接上屏或先进入候选。Mac 和 iOS 用同一套标点设置。

日期、时间和星期

输入 date、time、week，候选来自当时的系统时间。格式从「2026-10-09」到时间戳都有，用数字键选。

拼音反查

不会拆的字，用 z 加拼音反查。例如不知道「玫」时打 zmei，再从候选里选。
